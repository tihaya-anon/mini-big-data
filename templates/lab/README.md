# Lab Template

## Goal

Describe the smallest useful version of the system you want to build.

## Scope

### In scope

- Core behavior 1
- Core behavior 2
- Core behavior 3

### Out of scope

- Production hardening
- Full protocol compatibility
- UI, deployment, or ecosystem integrations unless they are central to the lab

## Architecture

Document the main components, data flow, and failure boundaries.

## Milestones

1. Define data model and interfaces.
2. Implement the write path.
3. Implement the read path or execution path.
4. Add recovery, checkpointing, or planning logic as needed.
5. Add tests and failure cases.

## Notes

Capture tradeoffs, shortcuts, and open questions here.
